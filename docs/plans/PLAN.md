## 2. NEXT.md Priority 1 Layer 2 — command sandbox (the real security gap)

Layer 1 stops an agent from *editing* outside the workspace via file tools. Layer 2 is
what stops it from *executing* outside the workspace — currently `run_task` runs raw
`subprocess.Popen` with the user's full privileges.

### Verified injection points (exactly 4)

| # | File | Line | What runs |
|---|---|---|---|
| 1 | `task_server/backends/posix.py` | 57 | `subprocess.Popen` — `run_task` shell (Linux/macOS) |
| 2 | `task_server/backends/windows.py` | 81, 92 | `subprocess.Popen` — `run_task` (Windows) |
| 3 | `task_server/tools/py_runner.py` | 77 | `subprocess.run` — `run_python` snippets |
| 4 | `task_server/tools/grep.py` | — | `execute_code_grep` shell-outs |

> All four sit **behind the Flask sidecar on :5000**. `src/server/routes/tasks.js` is a
> pure proxy, so no JS changes are needed to enforce this — the sandbox belongs in Python.

### Design
Create one module, `task_server/sandbox.py`, with a single entry point so all four
call sites share identical policy:

```python
def build_sandbox_argv(argv, *, cwd, allow_network=False, isolation="auto") -> list[str]
```

- **Engine detection** (cached at import): `bwrap` present + `CLONE_NEWUSER` usable →
  bubblewrap; Termux (`$PREFIX` startswith `/data/data`) → `proot`; otherwise `none`.
- **Writable set is exactly two paths**: project root + `$SCRATCH_DIR`/`$ARTIFACTS_DIR`.
  Everything else `--ro-bind`. `~/.ssh`, `~/.config`, `~/.aws` explicitly masked.
- **`AllowNetwork`** must default to *off* for the sandbox and gate `--unshare-net`.

### Tasks
7. Add `task_server/sandbox.py` with `detect_engine()` + `build_sandbox_argv()`, unit-testable
   with no `bwrap` installed (assert argv shape, not execution).
8. Add `[Security]` section to `config.ini` (`Isolation`, `AllowNetwork`, `ProtectDotfiles`)
   and read it in `task_server/config.py`.
9. Wire `posix.py:57` through `build_sandbox_argv` (highest value — this is the agent's shell).
10. Wire `py_runner.py:77` through it (`run_python` is an equally effective escape hatch —
    `__import__("os").system(...)` bypasses every JS-level guard).
11. Wire `windows.py` — note **bubblewrap/proot don't exist on Windows**; implement as
    a no-op with a startup warning, or gate behind explicit opt-in. Do not pretend it works.
12. Wire `grep.py`.
13. Verify escape attempts fail: `cat ~/.ssh/id_rsa`, `echo x > /etc/foo`,
    `cd /home/shado && ls -a` — each must be denied *inside* the sandbox.
14. **Escape-hatch UX:** `Isolation = none` must surface a clear warning in the UI, not
    fail silently. An agent silently running unconfined is worse than no sandbox.
